# Sources and licences

Data edition: see `sources/manifest.json` (first edition fetched 2026-11-11; Natural Earth and UDHR added 2026-11-12).

| Source | Used for | Licence |
|---|---|---|
| [mledoze/countries](https://github.com/mledoze/countries) | names, codes, capitals, borders, official languages | ODbL 1.0: attribution required; the derived country database must stay available under ODbL |
| [datasets/country-codes](https://github.com/datasets/country-codes) | UN M49 regions, Wikidata ids, capitals, FIPS codes | see repository (open data) |
| [CIA World Factbook](https://www.cia.gov/the-world-factbook/) via [factbook/factbook.json](https://github.com/factbook/factbook.json) | capitals, land borders, official and spoken languages, highest points, major rivers | public domain (US government work) |
| [Natural Earth](https://www.naturalearthdata.com/) 1:10m via [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector), 1:50m via [world-atlas](https://github.com/topojson/world-atlas) | the maps; positions of capitals and peaks; river courses | public domain |
| [Universal Declaration of Human Rights](https://www.ohchr.org/en/human-rights/universal-declaration/universal-declaration-human-rights/about-universal-declaration-human-rights-translation-project) in Unicode, via [NLTK's udhr2 corpus](https://github.com/nltk/nltk_data) | the language text samples (opening of Article 1) | OHCHR translations, quoted briefly with attribution; check OHCHR's terms of use before the public launch |
| [flag-icons](https://github.com/lipis/flag-icons) | flag images | MIT |

The site's credits page must name these sources and the data date.
